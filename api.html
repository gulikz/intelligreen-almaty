IntelliGreenAlmaty открытый API
К сервису

Открытый API

Данные отдаются статически по HTTPS, поэтому доступны из любого клиента без ключей и лимитов: QGIS и ArcGIS открывают GeoJSON по ссылке напрямую, скрипты — обычным HTTP-запросом. Лицензия — CC-BY 4.0: используйте свободно, указывая источник.

Точки доступа

GET /api/v1/hexes.geojson 2 365 кварталов Алматы: координаты, прогноз EcoRisk, вероятность высокого риска, NDVI, температура поверхности, число обращений, землепользование. Формат GeoJSON, EPSG:4326.
GET /api/v1/districts.json Сводка по восьми районам: средний EcoRisk, кварталы высокого риска, NDVI, обращения.
GET /api/v1/priority.json Сто приоритетных кварталов с координатами и рангом.
GET /api/v1/metrics.json Метрики модели: R², MAE, AUC, порог по цене ошибки, FNR и FPR, список признаков.
GET /data/model.json Сама модель: деревья XGBoost в компактном JSON. Её можно выполнить у себя — именно так и работает карта сервиса.

Пример: Python

import requests

base = "https://GHUSER.github.io/REPO"
hexes = requests.get(f"{base}/api/v1/hexes.geojson").json()
top = sorted(hexes["features"],
             key=lambda f: -f["properties"]["ecorisk"])[:10]
for f in top:
    p = f["properties"]
    lng, lat = f["geometry"]["coordinates"]
    print(f'{p["hex_id"]}  {p["district"]:12s}  EcoRisk {p["ecorisk"]:.2f}  {lat:.4f},{lng:.4f}')

Пример: выполнить модель у себя

Модель — это массив деревьев. Сравнение признака с порогом идёт в float32: в двойной точности маршрут по дереву иногда расходится с XGBoost, и прогноз уезжает.

Чего в демонстрации нет

Приём гражданских отчётов работает только в браузере посетителя: отчёт меняет признаки квартала и модель пересчитывает прогноз на месте, но на сервер ничего не уходит и другим посетителям не видно. В рабочей системе этот слой — PostgreSQL с PostGIS, FastAPI, очередь верификации, ограничение частоты и оценка доверия участника; статический хостинг для этого непригоден по определению.

Источник данных

Показаны данные пилотной модели: синтетический эко-двойник Алматы на 2 365 кварталов, где истинный EcoRisk известен по построению. Именно поэтому на сервисе можно честно показать ошибку прогноза — есть с чем сравнивать. В рабочей системе те же признаки приходят из Sentinel-2, Landsat, OpenStreetMap, открытого кадастра, WorldPop и SRTM.
